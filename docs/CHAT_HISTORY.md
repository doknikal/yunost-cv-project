## 5. Смена задачи: лендинг от преподавателя

**Пользователь:** я хочу облегчить и тебе и себе работу, может нам просто найти подходящее готовое решение по ocr и интегрировать его в нашу задачу? Преподаватель предложил сделать лендинг, на который юзер заливает фото страницы, а ocr распознает только прозу и выдает текст

**Ассистент (кратко).** Найдены варианты (веб-поиск): PaddleOCR, Surya, Tesseract, облачный Яндекс Vision OCR

Идея: выбор «проза/стихи» делает наш код по ровности правого края, OCR только читает. Результат — лендинг + API.

## 6. Реализация

**Пользователь:** давай бесплатный, пробные страницы можешь взять из файлов проекта

**Ассистент (кратко).** Сделано в ветке `feature/prose-ocr-landing`, PR #1 (черновик).

Сравнение движков: PaddleOCR проверить не удалось (сеть среды блокирует загрузку моделей, обход не делался),
выбран Tesseract (`rus`): 1–3 с на страницу, русский читает хорошо.

Ход разработки и найденные проблемы:
- Прозу и стихи нельзя разделять по странице или колонке: на одной странице бывают колонки прозы и рамка со стихами,
  поэтому решение принимается по блокам.
- Рамка страницы на фото склеивалась с текстом в один гигантский «блок прозы» → удаляются рамки, длинные вертикальные
  и горизонтальные линии (рамки, нотный стан).
- Блоки из 5 строк давали ложные срабатывания → минимум 8 строк; ровность правого края считается с поправкой на наклон.
- Вторая проверка по тексту OCR: доля строк с заглавной буквы (стихи), доля кириллицы и доля «настоящих» слов (ноты и мусор).
- Проверка вручную: вся проза на 6 страницах найдена; стихи на скане и фото отброшены. Известное ограничение: стихи
  с одинаковой длиной строк иногда проходят как проза (3 из ~10 просмотренных фото-страниц); блоки короче 8 строк не
  считаются прозой. На всём корпусе проза найдена на 21 странице из 111.

Состав: `yunost/blocks.py`, `yunost/ocr.py`, `yunost/pipeline.py`, `yunost/decorators.py`, `server.py` (FastAPI,
`POST /api/ocr`, `GET /api/health`), `static/index.html` (лендинг), `tests/test_prose.py` (11 тестов, включая HEIC),
обновлены `README.md` и `requirements.txt`. Лендинг проверен в браузере: страница с прозой, страница со стихами, файл не-картинка.

Оставшееся по требованиям парного проекта: база данных (SQLite), ещё 2 переопределённых метода, ещё декораторы,
интерактивные графики.
