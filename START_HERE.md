# «Юность» 1.3.0: локальный OCR и геометрия строк

Приложение распознает русский текст на фото или скане страницы: прозу, стихи, заголовки, подписи, короткие строки.
Жанр не отбирается. Физические строки и примерные отступы сохраняются.
Работает бесплатно на CPU, изображения во внешние сервисы не уходят.
Для курсового проекта добавлены SQLite и три настраиваемых графика.
Критерии и сценарий защиты: [COURSEWORK.md](COURSEWORK.md).

## Установка на macOS

1. Нужны **Python 3.9–3.12 и Tesseract 5**. Если их нет: `brew install python@3.12 tesseract`.
2. Запустите `install_mac.command` (или `bash install_mac.command`). Интернет нужен один раз:
   установщик скачает Python-библиотеки и проверенные русские веса.
3. Запустите `start_mac.command`. Откроется http://127.0.0.1:8000.
4. Загрузите JPG, PNG или HEIC. Для проверки подойдет `1967-12/page_3.png`.
   Текст можно править, копировать и скачать в UTF-8 как `.txt`.
5. Ссылка «Аналитика корпуса» ведет на http://127.0.0.1:8000/analytics.
   Там меняются годы, источник, признаки, число интервалов, среднее и медиана.
6. После OCR включите «Показать правые края строк». Фиолетовые точки показывают геометрию по пикселям,
   а не уверенность OCR. В «Проверить текстовые блоки» видны число строк CV и неровность края.
   Если данных мало, показано «нет оценки».

Если macOS блокирует `.command`, запустите его через `bash` в терминале.
Окружение создается в `.venv-app`. Существующая `.venv` и данные исследования не меняются.
Повторный запуск установщика безопасен, чужую папку `.venv-app` он не перезаписывает.

## Linux и Windows

Установите Python 3.9–3.12 и Tesseract 5, чтобы он был в `PATH`.
Ubuntu/Debian: `sudo apt install tesseract-ocr python3-venv`.
Windows: установщик Tesseract от UB Mannheim, папку с `tesseract.exe` добавьте в `PATH`.

```bash
python3 setup_app.py
.venv-app/bin/python run_app.py
```

На Windows: `py -3.12 setup_app.py`, затем `.venv-app\Scripts\python.exe run_app.py`.
Эти платформы не проверялись. Чистая установка проверена на macOS с Python 3.9.

## Если не работает

- Не закрывайте окно сервера. Остановка: **Ctrl+C**.
- Порт занят: `bash start_mac.command --port 8001`.
- Проверка движка: http://127.0.0.1:8000/api/health, ожидается `"status":"ok"`.
- «Другая страница еще распознается»: подождите и загрузите страницу заново. OCR берет одну страницу за раз.
- Тайм-аут: возьмите более четкий снимок или одну колонку. Лимит — 90 секунд на страницу и 30 секунд на один вызов Tesseract.
- Пустая страница даст пустой текст, без сообщения, что текста в оригинале нет.
- Файл: до 25 МиБ и 80 мегапикселей, одна страница, не анимация и не PDF.
  Большие загрузки могут временно записываться на диск, после обработки они удаляются.
- EXIF-поворот с телефона учитывается. Снимок, повернутый боком **без EXIF**, поверните вручную.
  Перспективу и разворот на 90° приложение само не исправляет.
- Страница приводится к высоте 2000 px, ширина не больше 4000 px.

## Данные и графики

При первом открытии аналитики создается `data/corpus.sqlite3`: 111 страниц, 15 номеров, девять признаков
из `manifest.csv` и `features.csv`. Дальше графики читают SQLite, а не CSV.
Загрузки OCR в корпус не попадают. Каталог `data` должен быть доступен для записи.
Другую базу укажите в `YUNOST_DB_PATH` перед запуском сервера.

Повторный импорт (дубликатов не создает, отсутствующие страницы не удаляет):

```bash
.venv-app/bin/python import_corpus.py
```

Windows: `.venv-app\Scripts\python.exe import_corpus.py`.
Своя база: добавьте `--database путь/к/корпусу.sqlite3`. Чужая база не перезаписывается.
Если база не открылась, аналитика отвечает 503, OCR работает.

Графики: гистограмма (признак, 2–60 интервалов), динамика (признак, среднее или медиана),
рассеяние (оси X и Y). Общие фильтры: годы и сканы/фото. Под каждым графиком есть таблица.
Пропуск `raggedness` хранится как NULL, не как ноль. Рядом показаны числа выбранных, использованных и пропущенных страниц.
Признаки описывают геометрию, качество OCR они не оценивают. Фото 1962–1965 — подборка в основном стихотворных страниц,
со сканами их напрямую сравнивать нельзя. Страницы одного номера зависимы.
Chart.js лежит в репозитории, лицензия MIT (`static/vendor/Chart.js.LICENSE.md`).

Графики используют **историческую** проекционную метрику: CSV и SQLite не пересчитывались.
Диагностика загруженной страницы работает по `components-v2` и ширине OCR-блока с полями,
поэтому ее значения нельзя смешивать с корпусными. Метод, проверка и известные ошибки: [EDGE_METHOD.md](EDGE_METHOD.md).

## Качество и границы

OCR **ошибается**. Сверяйте слова, начала и концы колонок, подписи и порядок блоков с оригиналом.
Уверенность OCR не равна проценту верных слов. Трудно даются изогнутые фото, декоративные буквы и рисунки.
Физические переносы остаются, литературный текст автоматически не собирается.

Повторное чтение блоков может заменить отдельное слово без изменения разметки, если отдельное чтение слова с ним совпадает.
Пунктуация не заменяется. Исходное чтение лежит в API в `words[].original_text`. Это тоже эвристика.
Веса: `tessdata_fast/rus`, лицензия Apache-2.0 (`tessdata/LICENSE`).
Tesseract и Python в архив **не входят**: это переносимый комплект приложения, а не готовый `.app` или `.exe`.
После установки распознавание работает без интернета.

API: `POST /api/ocr` (multipart, поле `file`), документация на `/docs`. Поле `edge_analysis` добавлено в 1.3.0,
текст, блоки и overlay остались прежними.
Аналитика: `GET /api/analytics/options`, `/histogram`, `/trend`, `/scatter`
(последние три доступны и с префиксом `/api/analytics`). Параметры перечислены в `/docs`.
Ошибки: 400 — не изображение, 413 — большой файл, 429 — OCR занят, 504 — тайм-аут, 500 — сбой движка.
Приложение локальное. Для публикации в интернете ему нужны отдельная защита и авторизация.
