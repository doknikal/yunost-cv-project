# «Юность» 1.2.0: локальный OCR и аналитика корпуса

Распознаёт русский текст без жанрового отбора: проза, стихи, заголовки,
подписи и короткие строки. Сохраняет физические строки и примерные отступы.
Бесплатно, на CPU; изображения не отправляются во внешние OCR-сервисы.
Для курсового проекта добавлены SQLite и три настраиваемых графика.
Карта требований и сценарий защиты: [COURSEWORK.md](COURSEWORK.md).

## Установка на macOS

1. Распакуйте архив в отдельную папку. Нужны **Python 3.9–3.12 и Tesseract 5**.
   При необходимости: `brew install python@3.12 tesseract`.
2. Откройте `install_mac.command` (или `bash install_mac.command` в терминале).
   Интернет нужен один раз для Python-библиотек. Русские веса уже включены в архив.
3. Откройте `start_mac.command`. Откроется http://127.0.0.1:8000.
4. Загрузите JPG/PNG/HEIC. Для проверки есть `examples/page_3.png`.
   Текст можно редактировать, копировать и скачивать в UTF-8 `.txt`.
5. Ссылка «Аналитика корпуса» открывает http://127.0.0.1:8000/analytics.
   Меняйте годы/источник, признаки, число интервалов и среднее/медиану.

Если macOS блокирует `.command`, запустите его через `bash` из терминала.
При запуске из репозитория, а не архива, установщик также скачает проверенные веса.
Окружение создаётся в `.venv-app`; существующая `.venv` и исследовательские данные не изменяются.
Повторный запуск установщика безопасен. Чужая папка `.venv-app` не перезаписывается.

## Linux / Windows

Установите Python 3.9–3.12 и Tesseract 5, доступный в `PATH`.
На Ubuntu/Debian: `sudo apt install tesseract-ocr python3-venv`.
На Windows: установщик Tesseract от UB Mannheim; добавьте папку с `tesseract.exe` в `PATH`.

```bash
python3 setup_app.py
.venv-app/bin/python run_app.py
```

На Windows команды: `py -3.12 setup_app.py`, затем `.venv-app\Scripts\python.exe run_app.py`.
Эти платформы здесь не проверялись; свежая установка проверялась на macOS/Python 3.9.

## Если не работает

- Не закрывайте окно сервера; остановка — **Ctrl+C**.
- Порт занят: `bash start_mac.command --port 8001`.
- Проверка движка: http://127.0.0.1:8000/api/health — ожидается `"status":"ok"`.
- «Другая страница ещё распознаётся»: подождите и загрузите заново. Одна OCR-задача за раз.
- Тайм-аут: более чёткий снимок или отдельная колонка; предел OCR — 90 секунд на страницу,
  один вызов Tesseract — не более 30 секунд.
- Пустая страница даёт пустой текст, а не сообщение об отсутствии текста в оригинале.
- Файл: не более 25 МиБ и 80 мегапикселей, одна страница, не анимация/PDF.
  Большие загрузки могут временно записываться на диск и удаляются после обработки.
- Телефонный EXIF-поворот учитывается. Снимок, повёрнутый боком **без EXIF**, нужно повернуть вручную.
  Автоматическое исправление перспективы и разворота на 90° не выполняется.
- Обычные страницы нормализуются до высоты 2000 px; ширина ограничена 4000 px.

## Данные и графики

При первом открытии аналитики создаётся `data/corpus.sqlite3`: 111 страниц,
15 номеров, девять признаков из включённых `manifest.csv` и `features.csv`.
После импорта графики читают SQLite, а не CSV. Пользовательские OCR-загрузки
в корпус не добавляются. Каталог `data` должен быть доступен для записи.
Для другой базы задайте `YUNOST_DB_PATH` перед запуском сервера.

Явный повторный импорт (дубликатов не создаёт, отсутствующие страницы не удаляет):

```bash
.venv-app/bin/python import_corpus.py
```

Windows: `.venv-app\Scripts\python.exe import_corpus.py`.
Своя база: добавьте `--database путь/к/корпусу.sqlite3`; чужая база не перезаписывается.
Ошибка открытия базы — 503 только для аналитики; OCR продолжает работать.

Графики: гистограмма (признак, 2–60 интервалов), динамика (признак,
среднее/медиана), рассеяние (оси X/Y). Общие фильтры: годы и сканы/фото.
Под каждым графиком есть таблица. Пропуск `raggedness` — NULL, не ноль;
показываются числа выбранных, использованных и пропущенных страниц.
Это признаки геометрии, не оценка OCR. Фото 1962–1965 — выбранная преимущественно
поэтическая подборка, не сопоставимая напрямую со сканами; страницы одного номера
зависимы. Chart.js включён локально, MIT (`static/vendor/Chart.js.LICENSE.md`).

## Качество и границы

Это **не безошибочная транскрипция**. Проверяйте слова, начало/конец колонок,
подписи и порядок блоков по оригиналу. Уверенность OCR — не процент правильности.
Особенно сложны изогнутые фотографии, декоративные буквы и рисунки.
Физические переносы оставляются; это не автоматическая сборка литературного текста.

Осторожное перечитывание блоков может заменить отдельное слово, не меняя разметку;
нужно совпадение отдельного чтения слова. Пунктуация не заменяется.
Исходное чтение сохраняется в API в `words[].original_text`. Это тоже эвристика.
Веса: `tessdata_fast/rus`, Apache-2.0 (текст лицензии — `tessdata/LICENSE`).
Сам Tesseract и Python **не встроены** в архив; это переносимый комплект приложения,
а не автономный `.app`/`.exe`. После установки распознавание работает без интернета.

API: `POST /api/ocr`, multipart-поле `file`; документация — `/docs`.
Аналитика: `GET /api/analytics/options`, `/histogram`, `/trend`, `/scatter`
(последние три также с префиксом `/api/analytics`). Настройки перечислены в `/docs`.
Ошибки: 400 — изображение, 413 — размер, 429 — занято, 504 — тайм-аут,
500 — сбой движка. Приложение предназначено для локального использования,
не для публикации в интернете без отдельной защиты и авторизации.
