# Визуальная оттепель — CV-анализ вёрстки журнала «Юность» (1957–1967)

Итоговый проект по курсу «Программирование для цифровых гуманитарных проектов».
Тип — исследовательский. Объект — графический облик страниц журнала «Юность».
Методы — **классическое компьютерное зрение** (OpenCV/NumPy/SciPy/scikit-learn), без нейросетей.

## Главный результат
Между 1957 и 1967 гг. значимо выросла типографическая «рваность» правого края страниц
(медиана 0.125→0.189; Манна–Уитни p≈7·10⁻⁶; размер эффекта 0.63) и число колонок —
измеримый отпечаток эстрадной поэзии. Иллюстративность при этом не выросла («нулевой» результат).

## Лендинг: проза со страницы журнала → текст
Загружаете фото или скан страницы — сервис находит блоки **прозы** и распознаёт их текст.
Стихи, заголовки, иллюстрации и рамки пропускаются. Файлы нигде не сохраняются.

**Установка.** Кроме `pip install -r requirements.txt` нужен сам OCR-движок Tesseract с русским языком:
```bash
brew install tesseract tesseract-lang            # macOS
sudo apt install tesseract-ocr tesseract-ocr-rus # Ubuntu/Debian
# Windows: установщик UB-Mannheim, при установке отметить Russian; tesseract.exe добавить в PATH
```
**Запуск.**
```bash
uvicorn server:app --reload     # лендинг: http://127.0.0.1:8000/   API-документация: /docs
pytest tests/                   # тесты
```
**API.** `POST /api/ocr` (поле `file`: JPG/PNG/HEIC до 25 МБ) → JSON: `text`, `prose_blocks`, `blocks`
(координаты, число строк, ровность), `overlay` (страница с разметкой, PNG в base64). `GET /api/health` — проверка Tesseract.

**Как это устроено** (пакет `yunost/`):
1. `BlockDetector` (`blocks.py`) — убирает иллюстрации, рамки и линии, склеивает строки в блоки и для каждого
   считает **ровность правого края**: проза набрана «в формат», у стихов край рваный. Это та же идея, что и в
   исследовании («рваность» → признак стиха), только теперь она отбирает, что читать.
2. `OcrEngine` / `TesseractEngine` (`ocr.py`) — читают только блоки-прозу, по одному (так колонки не смешиваются).
   Другой движок подключается наследником `OcrEngine` с методом `read_lines()`.
3. Вторая проверка по прочитанному тексту (`ProseExtractor._verify`): отсеивает стихи с ровными строками
   (почти все строки с заглавной буквы) и блоки, где вместо текста ноты или рисунок.
4. Склейка текста: красная строка начинает абзац, перенесённые слова склеиваются.

**Ограничения.** Проверено вручную на страницах из корпуса: вся проза на 6 проверенных страницах найдена, стихи на
скане и на фото отброшены. Но: блоки короче 8 строк не считаются прозой (мало данных); стихи с одинаковой длиной строк
иногда проходят как проза (так было на 3 из ~10 просмотренных страниц с фото); фото с сильным перекосом и тенями
распознаются хуже сканов. Пороги собраны в `ProseSettings` (`yunost/blocks.py`).
