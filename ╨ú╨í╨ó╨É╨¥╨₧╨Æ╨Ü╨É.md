# Как открыть и запустить Yunost_CV_project.ipynb

## Вариант 0 — без установки (для чтения/проверки)
Ноутбук **уже содержит все результаты и графики**. Чтобы просто посмотреть:
- открой `Yunost_CV_project.html` в любом браузере, или
- открой `.ipynb` в VS Code и листай — выполнять ячейки не обязательно.

## Вариант 1 — автоустановка (рекомендую)
В Finder **дважды кликни `setup_mac.command`**. Скрипт создаст изолированное
окружение `.venv`, поставит все библиотеки и зарегистрирует ядро Jupyter.
Если macOS заблокирует запуск: правый клик → «Открыть» → «Открыть».

После этого в VS Code: открой ноутбук → «Select Kernel» (вверху справа) →
выбери **.venv** или **Python (Yunost CV)** → Run All.

## Вариант 2 — вручную в терминале
```bash
cd "путь/к/Yunost_CV_project"
python3 -m venv .venv
source .venv/bin/activate
pip install -U pip
pip install -r requirements.txt
python -m ipykernel install --user --name yunost-cv --display-name "Python (Yunost CV)"
python prep_package.py        # регенерирует data/norm из ../1967-12 (нужно для ячеек с картинками)
```
Затем в VS Code выбери интерпретатор `.venv`.

## Интерпретатор
Окружение собирается на **Homebrew-Python** `/opt/homebrew/bin/python3` (3.14.6).
Под него есть готовые пакеты (wheels) для Apple Silicon — компиляции не требуется.
Системный `/usr/bin/python3` (3.9.6) не используется.


## Вариант 3 — Windows (PowerShell)
```powershell
cd "C:\путь\к\Yunost_CV_project"
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe prep_package.py    # регенерирует data\norm и manifest.csv из 1967-12\
```
Затем открой ноутбук в VS Code, выбери интерпретатор `.venv` и Run All — либо без VS Code:
```powershell
.venv\Scripts\python.exe -m jupyter nbconvert --to notebook --execute --inplace Yunost_CV_project.ipynb
```
Инструмент по строфам: `.venv\Scripts\python.exe overlay.py` (создаёт `output_1962-12\`).
